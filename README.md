# Rangitoto-Introduction-To-Programming-2026-BIG-PROJECT
2D action platformer built in Python with Pygame, designed both as a playable game and a teaching project for beginner and intermediate programmers. Players control a dash-enabled character, navigate tile-based levels, fight ranged enemies, and experience polished visual effects like particles, sparks, and parallax star fields.

Run the main.py to run the game! Arrow keys to move and "X" to dash!

Run editor.py to run the tilemap editor to make your own levels! 
Scorll for different objects, click for placing and removing, and "O" to output the .json file!

When editing your own levels, there are a few useful commands to make it easier!
    + You can hold "Shift" and scroll through a specific block for its variants.
    + When creating an border (e.g a box of stone blocks), fill it with your desired block and press "T" to auto-complete it. This will fully create the platform with the correct block variants.
    + Pressing "G" will allow objects to go offgrid - useful for more free-loaded objects such as trees and flowers, pressing "G" again will come back to placing on the grid
